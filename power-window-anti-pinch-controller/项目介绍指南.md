# Power Window Anti-Pinch Controller 项目介绍指南

## 项目概述

Power Window Anti-Pinch Controller（车窗防夹控制器）是一个完整的嵌入式应用软件系统，专为汽车电动车窗控制而设计。该项目采用模块化架构，严格遵循 AUTOSAR 标准，实现了车窗的智能控制、安全保护和故障诊断功能。

### 核心价值

- **安全性优先**: 实现防夹保护、过流保护、欠压保护等多重安全机制
- **智能化控制**: 支持手动/自动升降、一键操作、学习功能
- **高可靠性**: 完整的故障诊断、数据持久化、错误恢复机制
- **工业级标准**: 遵循 AUTOSAR 架构，符合汽车行业标准
- **全面测试**: 95%+ 代码覆盖率，包含单元测试和属性测试

## 技术架构

### 系统架构图

```
PowerWindow (主控模块)
├── PowerWindow_StateMachine (状态机管理)
├── PowerWindow_Safety (安全监控)
├── PowerWindow_NvM (非易失性存储)
├── PowerWindow_Diag (诊断接口)
└── PowerWindow_Interface (硬件抽象)
```

### 核心技术特点

#### 1. 模块化设计
- **6个独立模块**: 每个模块职责单一，接口清晰
- **无循环依赖**: 严格的依赖层次，便于维护和测试
- **可插拔架构**: 支持不同硬件平台的适配

#### 2. 状态机管理
- **8个系统状态**: 覆盖所有操作模式和异常情况
- **完整状态转换**: 定义了所有有效的状态转换路径
- **安全优先**: 故障状态具有最高优先级

#### 3. 安全保护机制
- **防夹保护**: 实时电流监测，检测夹物并自动回退
- **电气保护**: 过流、欠流、欠压多重保护
- **位置保护**: 上下限位保护，防止机械损坏

#### 4. 智能功能
- **自动学习**: 自动学习车窗上下限位置
- **一键操作**: 支持一键升降功能
- **参数标定**: 支持不同车型的参数配置

## 功能特性

### 主要功能

#### 1. 车窗控制功能
- **手动控制**: 按钮按下时车窗移动，释放时停止
- **自动控制**: 短按触发一键升降至目标位置
- **位置精确**: 0-100% 精确位置控制和显示

#### 2. 防夹保护功能
- **实时监测**: 10ms 周期监测电机电流
- **智能检测**: 电流超阈值时触发防夹保护
- **自动回退**: 检测到夹物后自动回退设定距离
- **安全锁定**: 防夹后禁止自动升窗 5 秒

#### 3. 故障诊断功能
- **7种故障码**: 覆盖传感器、电气、存储等故障
- **实时诊断**: 持续监控系统健康状态
- **历史记录**: 保存故障历史用于维护分析
- **故障恢复**: 自动检测故障清除并恢复功能

#### 4. 数据持久化
- **关键数据保存**: 位置、学习状态、故障记录
- **数据完整性**: CRC32 校验确保数据可靠性
- **智能保存**: 条件触发保存，减少存储器磨损
